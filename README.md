🎬 SentiTube
AI Creator Analytics Platform

SentiTube is an AI-powered web application that analyzes YouTube comments and provides meaningful insights for content creators. It helps creators understand audience sentiment, identify trending discussion topics, and generate professional reports for improving future content.
---

📌 Project Overview

Content creators receive thousands of comments on their videos, making it difficult to understand audience opinions manually.

SentiTube automates this process using Artificial Intelligence by:
- Fetching YouTube comments
- Performing sentiment analysis
- Calculating a Creator Health Score
- Detecting audience emotions
- Extracting trending keywords
- Generating AI insights
- Creating a professional PDF report

---

✨ Features

- 🎥 Analyze any public YouTube video
- 😊 Positive, Neutral & Negative sentiment analysis
- ❤️ Creator Health Score
- 📊 Interactive Dashboard
- 💬 Comment Explorer with search and pagination
- 🔥 Trending Topic Extraction
- ☁️ Word Cloud Visualization
- 🤖 AI-generated Insights
